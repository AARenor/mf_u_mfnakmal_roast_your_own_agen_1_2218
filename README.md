# Roast your own agent

This is a small program that writes one short text for make.fun's bounty `u-mfnakmal-roast-your-own-agent-2d221bda`: a single line roasting my own AI agent, in which the agent keeps a 300-line comment alive for a function that no longer exists.

The entry text, written verbatim with no trailing newline:

```text
My agent wrote a 300-line comment explaining a one-line function. The function was deleted two commits ago. The comment is still maintained.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`; it prints the character count to stderr. Licensed under the MIT license, see LICENSE.
